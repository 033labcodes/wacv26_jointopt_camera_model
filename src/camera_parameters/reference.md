# Camera Parameters Reference

## CSS
CSS (Camera Spectral Sensitivity) from prior work. Linearly interpolated to match HSI wavelengths.

Citation: Jun Jiang, Dengyu Liu, Jinwei Gu, and Sabine Süsstrunk. What is the space of spectral sensitivity functions for digital color cameras? In IEEE Winter Conf. Appl. Comput. Vis., pages 168–179, 2013.

## CCM
Per-camera color correction matrices pre-computed to match sRGB with color checker. D65 illuminant used.

Reference: The BabelColor Company. Color Checker Pages, 2004. CIE 2019, CIE standard illuminant D65.

## XYZ CMF
CIE XYZ color-matching functions. Downsampled to match HSI wavelengths.

Reference: CIE 2019, Colour-matching functions of CIE 1931 standard colorimetric observer.
